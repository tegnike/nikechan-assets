# AIニケちゃん 音声関連素材

このフォルダには、AIニケちゃんの試聴・閲覧・参考用ファイルが格納されています。これらのファイルは素材として利用できません。

利用前に、このREADMEと次のガイドラインを必ずご確認ください。

- [二次創作ガイドライン](../guidelines/derivative_creation_guideline.md)
- [AI生成ガイドライン](../guidelines/ai_generation_guideline.md)
- [個別提供ボイスアセット利用ガイドライン](VOICE_ASSET_GUIDELINE.md)

## ファイル一覧

- `sample.wav` - AIニケちゃんの音声サンプル
- `ohirome_music_video.mp4` - AIニケちゃんのお披露目ミュージックビデオ
- [`scripts/`](scripts/README.md) - 音声収録に使用した台本

## このフォルダ内のファイルは利用できません

`sample.wav`、`ohirome_music_video.mp4`、`scripts/` 内の台本等は、試聴・閲覧・参考のために公開しています。次の利用は禁止です。

- 転載、複製、切り出し、編集、改変、翻訳、朗読
- 動画、配信、ゲーム、アプリ、音楽、音声作品等への組み込み
- 公開、配布、再配布
- 商用・非商用を問わず、素材として利用すること

## 生成AIへの利用は禁止です

AI生成ガイドラインで生成AIへの入力・参照・学習・変換が認められている公式素材は、VRMモデル3種とロゴ画像のみです。

そのため、このフォルダ内の音声、動画、台本、スクリーンショット等を、音声合成、ボイスチェンジ、文字起こしを含む生成AIの入力・参照・学習・変換に利用することはできません。

## ボイスアセットを利用したい場合

用途を記載して、作者X（[@tegnike](https://x.com/tegnike)）へDMで申請してください。作者から個別に提供されたボイスアセットのみ、提供時に案内する条件の範囲で利用できます。

このフォルダ内の公開ファイルが、申請後に利用できるアセットへ自動的に切り替わるわけではありません。

個別提供を受けた方は、提供時の通知と[ボイスアセット利用ガイドライン](VOICE_ASSET_GUIDELINE.md)を必ず確認してください。提供時の通知に記載のない利用は許可されません。

## 合成音声モデルについて

申請制でAIニケちゃんの合成音声モデルを個別提供しています。
以下のツールでの利用が可能です。

- Style-Bert-VITS2
- AIvisSpeech

これらのモデルは、**AIニケちゃんの声として利用する場合のみ**使用できます。モデルの利用、生成音声の公開・配布、収益化等については、提供時に案内する個別条件に従ってください。

個別提供されたボイスアセットや合成音声モデルの原本・改変版を再配布することはできません。

提供者が個別提供時に使用する通知書は、[個別提供通知テンプレート](PROVISION_NOTICE_TEMPLATE.md)を参照してください。
