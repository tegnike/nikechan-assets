# voice

このフォルダには、AIニケちゃんの音声関連ファイルが格納されています。

## ファイル一覧

### sample.wav
音声サンプルファイルです。

### scripts
音声収録に使用した台本データです。<br>
実際の収録データは非公開ですが、オリジナルボイス作成時の参考にしてください。

## 合成音声モデルについて

申請制でAIニケちゃんの合成音声モデルを配布しています。
以下のツールでの利用が可能です。

- Style-Bert-VITS2
- AIvisSpeech

これらのモデルは、**AIニケちゃんの声として利用する場合のみ**使用可能です。<br>
興味がある方は、管理者のXアカウント（[@tegnike](https://x.com/tegnike)）までご連絡ください。
