## 生成AIへの利用は禁止です

AI生成ガイドラインで生成AIへの入力・参照・学習・変換が認められている公式素材は、VRMモデル3種、ロゴ画像、公式サイトの各キャラクターページで公開している三面図・設定画、および個別提供時に許可されたボイスアセットです。このフォルダの公開台本は許可素材に含まれないため、生成AIへの入力、参照、学習、変換、データセット化等に利用することはできません。

## 利用禁止事項

閲覧・参考の範囲を超える、次の利用は禁止です。

- 全文または一部の転載、複製、再配布
- 改変、翻訳、朗読
- 音声作品、動画、配信、ゲーム、アプリ等への組み込み
- 商用・非商用を問わず、素材として利用すること

AIニケちゃんのボイスアセットを利用したい場合は、用途を記載して作者X（[@tegnike](https://x.com/tegnike)）へのDM、または[公式Discord](https://discord.com/invite/G4E5Sf3yj3)内で作者へのDMにより申請してください。個別に提供されたアセットのみ、ボイスアセット利用ガイドラインを基本条件とし、提供時の個別通知で定めた範囲で利用できます。
