# AIニケちゃん 音声収録台本

このフォルダには、AIニケちゃんの音声収録に使用した台本を収録しています。これらは閲覧・参考用であり、素材として利用できません。

## 利用前に確認するもの

- [音声関連素材のREADME](../README.md)
- [二次創作ガイドライン](../../guidelines/derivative_creation_guideline.md)
- [AI生成ガイドライン](../../guidelines/ai_generation_guideline.md)

## 生成AIへの利用は禁止です

AI生成ガイドラインで生成AIへの入力・参照・学習・変換が認められている公式素材は、VRMモデル3種とロゴ画像のみです。そのため、このフォルダの台本を生成AIへの入力、参照、学習、変換、データセット化等に利用することはできません。

## 利用禁止事項

閲覧・参考の範囲を超える、次の利用は禁止です。

- 全文または一部の転載、複製、再配布
- 改変、翻訳、朗読
- 音声作品、動画、配信、ゲーム、アプリ等への組み込み
- 商用・非商用を問わず、素材として利用すること

AIニケちゃんのボイスアセットを利用したい場合は、用途を記載して作者X（[@tegnike](https://x.com/tegnike)）へDMで申請してください。個別に提供されたアセットのみ、提供時に案内する条件の範囲で利用できます。
