# AIニケちゃんファミリー ガイドライン

AIニケちゃん、ニケ、ミカゼ、ぷにけ、今日は何の日botのアセットや二次創作を利用する前に、目的に応じて次のガイドラインをご確認ください。

一般的な利用条件の正本は、公式サイトで公開している[二次創作ガイドライン](https://nikechan.com/guidelines/derivative)と[生成AIガイドライン](https://nikechan.com/guidelines/ai)です。このフォルダの文書は、アセット利用時に確認しやすくするための複製です。

## [二次創作ガイドライン](derivative_creation_guideline.md)

対象キャラクターに依拠したイラスト、漫画、ノベル、3D、動画、配信、ゲーム、音楽、ボイス、素材、同人誌等に共通する条件を定めています。

主な内容は次のとおりです。

- 非営利の定義と、SNS・動画配信における条件付き収益化
- デジタル作品・素材・印刷物の配布条件
- 公式アセットの原本・改変版の再配布禁止
- 公開ボイスファイルの利用禁止と、ボイスアセットのDM申請方法
- 成人向け表現の条件
- 非公式ファンメイド表記
- 禁止事項、免責、問い合わせ方法

## [AI生成ガイドライン](ai_generation_guideline.md)

生成AIによる画像、動画、音声、テキスト、3D、モーション等の生成・学習・変換・配布に関する追加条件を定めています。

特に重要な点は次のとおりです。

- 生成AIに入力・参照できる公式素材は、VRMモデル3種、ロゴ画像、公式サイトの各キャラクターページで公開している三面図・設定画、および個別提供時に許可されたボイスアセットです。
- ボイスアセットはX DMまたは公式Discord内の作者へのDMで申請し、個別提供されたものだけ利用できます。
- 個別提供を受けた方は、[ボイスアセット利用ガイドライン](../voice/VOICE_ASSET_GUIDELINE.md)と提供時の個別通知を確認してください。
- それ以外の公式素材や、許諾を得ていない第三者の二次創作物は利用できません。
- AI生成物、学習済みモデル、LoRA、Embedding、ワークフロー、データセット等の公開・配布にも両ガイドラインが適用されます。

## 適用関係

通常の二次創作には二次創作ガイドラインが適用されます。生成AIを使う場合は、二次創作ガイドラインに加えてAI生成ガイドラインも適用されます。

一般条件について記載に差異がある場合は、公式サイトの詳細版ガイドラインを優先します。個別提供されたアセットには、専用ガイドラインを基本条件として適用し、案件固有の条件・例外は提供時の個別通知で定めます。各アセットフォルダのREADMEは、アセット固有の条件を補足するものです。

VRMモデルとBlenderデータ（`.blend`）の編集・レンダリング・再配布に関する補足条件は、[VRM・BlenderデータのREADME](../vrms/README.md)をご確認ください。
