# AIニケちゃん ガイドライン

AIニケちゃんのアセットや二次創作を利用する前に、目的に応じて次のガイドラインをご確認ください。

## [二次創作ガイドライン](derivative_creation_guideline.md)

AIニケちゃんに依拠したイラスト、漫画、ノベル、3D、動画、配信、ゲーム、音楽、ボイス、素材、同人誌等に共通する条件を定めています。

主な内容は次のとおりです。

- 非営利の定義と、SNS・動画配信における条件付き収益化
- デジタル作品・素材・印刷物の配布条件
- 公式アセットの原本・改変版の再配布禁止
- 公開ボイスファイルの利用禁止と、ボイスアセットのDM申請方法
- 成人向け表現の条件
- 非公式ファンメイド表記
- 禁止事項、免責、問い合わせ方法

## [AI生成ガイドライン](ai_generation_guideline.md)

生成AIによる画像、動画、音声、テキスト、3D、モーション等の生成・学習・変換・配布に関する追加条件を定めています。

特に重要な点は次のとおりです。

- 生成AIに入力・参照できる公式素材は、VRMモデル3種とロゴ画像のみです。
- ボイスアセットは作者XへのDM申請後に個別提供されたものだけ、提供時の条件に従って利用できます。
- それ以外の公式素材や、許諾を得ていない第三者の二次創作物は利用できません。
- AI生成物、学習済みモデル、LoRA、Embedding、ワークフロー、データセット等の公開・配布にも両ガイドラインが適用されます。

## 適用関係

通常の二次創作には二次創作ガイドラインが適用されます。生成AIを使う場合は、二次創作ガイドラインに加えてAI生成ガイドラインも適用されます。

各アセットフォルダのREADMEは、利用時に確認しやすいよう条件を要約したものです。記載に差異がある場合は、このフォルダ内の詳細なガイドラインを優先してください。
